# Spring Boot 4.1.0 中文翻译方案

## 目标

基于 Spring Boot `v4.1.0` 的 Antora/AsciiDoc 文档源，生成一个可本地构建和预览的中文文档站 MVP。

## 上游来源

- 官方文档：https://docs.spring.io/spring-boot/index.html
- 上游仓库：https://github.com/spring-projects/spring-boot
- 固定版本：`v4.1.0`
- 文档源目录：`documentation/spring-boot-docs/src/docs/antora`

## MVP 翻译范围

第一阶段只翻译核心入口页和教程入口页：

- `ROOT/pages/index.adoc`
- `ROOT/pages/documentation.adoc`
- `ROOT/pages/community.adoc`
- `ROOT/pages/system-requirements.adoc`
- `ROOT/pages/installing.adoc`
- `ROOT/pages/upgrading.adoc`
- `tutorial/pages/index.adoc`
- `tutorial/pages/first-application/index.adoc`

非 MVP 模块如 `reference`、`how-to`、`api`、`appendix` 暂不翻译。

## 生成流程

1. `npm run sync:source` 同步上游 `v4.1.0` 文档源到 `.cache/spring-boot-v4.1.0`。
2. `npm run translate:mvp` 调用 DeepSeek 翻译 MVP 页面，输出到 latest 版本内容根目录，例如 `versions/4.1.0/content/boot/**`。
3. `npm run validate` 校验 AsciiDoc 结构、关键术语、xref 和密钥泄露风险。
4. `npm run build` 使用 Antora 生成 `build/site`。
5. `npm run serve` 本地预览中文静态站。

全量翻译使用：

```bash
npm run translate:all
```

详细范围见 `docs/全量翻译方案.md`。

## DeepSeek 配置

- 默认模型：`deepseek-v4-flash`。
- API 地址：`https://api.deepseek.com/chat/completions`。
- 密钥来源：`DEEPSEEK_API_KEY` 环境变量或本地 `.env` 文件。
- 翻译脚本必须支持断点续跑，避免重复消耗 API。
