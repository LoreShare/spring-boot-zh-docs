# 文档源同步

## 目标

`npm run sync:source` 负责把 Spring Boot `v4.1.0` 的 Antora 文档源同步到本地缓存目录，供翻译脚本读取。

## 上游配置

- 仓库：`https://github.com/spring-projects/spring-boot.git`
- 版本：`v4.1.0`
- 稀疏目录：`documentation/spring-boot-docs/src/docs/antora`
- 缓存目录：`.cache/spring-boot-v4.1.0`

## 行为

- 如果缓存目录不存在或不是 Git 仓库，执行稀疏克隆。
- 如果缓存目录已经存在，拉取上游并切换到 `v4.1.0`。
- 同步脚本只写入 `.cache/`，不修改中文内容目录。
- `.cache/` 不提交到 Git。

## 验收

同步后必须存在：

```text
.cache/spring-boot-v4.1.0/documentation/spring-boot-docs/src/docs/antora/antora.yml
```
