# Antora 构建配置

## 目标

`npm run build` 使用 Antora 把 `content/boot` 中的中文 AsciiDoc 内容生成到 `build/site`。

## 内容源

Antora playbook 使用当前仓库作为本地内容源：

```yaml
content:
  sources:
  - url: .
    branches: HEAD
    start_path: content/boot
```

## 中文组件

中文内容组件位于 `content/boot`，组件名保持为 `boot`，版本固定为 `4.1.0`。

导航只包含 MVP 页面：

- 首页
- 文档概览
- 社区
- 系统要求
- 安装
- 升级
- 教程
- 开发第一个 Spring Boot 应用

## 输出

- 静态站点目录：`build/site`
- 本地预览命令：`npm run serve`
- 默认预览地址：`http://localhost:8080`

## UI bundle

使用 Antora 官方默认 UI 的稳定构建产物：

