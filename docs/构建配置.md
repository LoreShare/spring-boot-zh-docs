# Antora 构建配置

## 目标

`npm run build` 使用 Antora 把 `content/boot` 中的中文 AsciiDoc 内容生成到 `build/site`。

## 内容源

Antora playbook 使用当前仓库作为本地内容源：

```yaml
content:
  sources:
  - url: .
    branches: HEAD
    start_path: content/boot
```

## 中文组件

中文内容组件位于 `content/boot`，组件名保持为 `boot`，版本固定为 `4.1.0`。

导航使用上游顶层 `nav.adoc`，并通过其中的 include 指令串起全部已翻译模块：

- ROOT
- tutorial
- reference
- how-to
- build-tool-plugin
- cli
- api
- specification
- appendix

## 输出

- 静态站点目录：`build/site`
- 本地预览命令：`npm run serve`
- 默认预览地址：`http://localhost:8080`
- 当前内容不包含官方构建时生成的 Javadoc、Kotlin API、Actuator REST API、Maven 插件文档和 Gradle 插件文档；这些生成模块导致的 xref 错误允许作为日志保留，不让它们中断静态站生成。
