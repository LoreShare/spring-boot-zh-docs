# Spring Boot 4.1.0 全量翻译方案

## 目标

在当前项目中把已同步的 Spring Boot `v4.1.0` Antora 文档源完整生成中文内容。

## 范围

翻译范围以本地缓存为准。当前同步四个上游 Antora 源目录：

```text
.cache/spring-boot-v4.1.0/documentation/spring-boot-docs/src/docs/antora
.cache/spring-boot-v4.1.0/build-plugin/spring-boot-maven-plugin/src/docs/antora
.cache/spring-boot-v4.1.0/build-plugin/spring-boot-gradle-plugin/src/docs/antora
.cache/spring-boot-v4.1.0/documentation/spring-boot-actuator-docs/src/docs/antora
```

同时同步官方文档示例源码，用于展开 `include-code::` 自定义宏：

```text
.cache/spring-boot-v4.1.0/documentation/spring-boot-docs/src/main/java
.cache/spring-boot-v4.1.0/documentation/spring-boot-docs/src/main/kotlin
.cache/spring-boot-v4.1.0/documentation/spring-boot-docs/src/test/java
.cache/spring-boot-v4.1.0/documentation/spring-boot-docs/src/test/resources
```

纳入全量处理：

- `modules/**/pages/**/*.adoc`
- `modules/**/partials/**/*.adoc`
- 顶层 `nav.adoc`
- Maven Plugin、Gradle Plugin 和 Actuator REST API 的 Antora `.adoc` 页面、partial 与示例文件

复制但不翻译：

- `modules/ROOT/pages/redirect.adoc`
- 非 `.adoc` 文件，例如 `modules/reference/partials/dockerfile`
- `modules/**/examples/**` 示例文件

构建前本地展开：

- `include-code::...[]` 自定义宏展开为 `[source,java]` 或 `[source,kotlin]` 代码块。
- `tag=*`、`tag=name`、`tag=!name` 按官方示例源码中的 tag 标记截取。
- 解析失败时停止构建和校验，并输出具体页面、行号和宏名。

生成型内容处理：

- 上游官方构建流程生成的 include partial，例如配置属性表、插件目标表、Actuator REST API 请求/响应片段，必须从 Spring Boot 官方 Gradle 生成产物导入。
- 上游官方构建流程生成的 example 片段，例如远程 devtools 输出和 GraphQL schema 示例，必须从 Spring Boot 官方 Gradle 生成产物导入或从官方示例源码复制。
- 生成型 `.adoc` 内容中的自然语言使用 DeepSeek 翻译；REST 请求/响应、日志输出、GraphQL schema 等代码或输出示例保持原始结构和内容。
- 生成型内容导入后必须统一可见文案：专业术语、官方 endpoint ID、配置键、类名、命令、路径和协议名保持英文；普通说明、动作、描述和非专名标题使用中文；同一标题、导航项或面包屑来源不得出现“中文解释 (英文标识)”的重复并列。
- 中文站不得再生成“当前中文站暂未纳入完整生成内容”类占位 partial。若官方生成产物缺失，翻译或校验必须失败。

不在本轮范围：

- 官方构建时聚合的 Javadoc 和 Kotlin API 页面。
- Java API 和 Kotlin API 页面仍保留为外部英文参考链接，不生成中文镜像页面。

## 分块策略

较大的 `.adoc` 页面不能一次性发送给 DeepSeek，否则容易超过输出上限或返回截断 JSON。

翻译脚本按行分块：

- 优先把单块控制在约 `12,000` 字符以内。
- 不在 `----` listing/source 代码块内部切分。
- 代码块闭合后立即切分；如果该分块只包含代码块和结构占位符，则直接保留原文。
- 每个分块单独调用 DeepSeek。
- 如果分块只包含代码块、AsciiDoc 占位符或其他受保护内容，脚本直接复制原文，不调用 DeepSeek。
- `xref:`、`link:`、URL 宏的目标和属性必须保留，方括号中的可见链接文本应翻译。
- 页面标题、导航标签和正文普通说明必须遵守术语表，不得把可翻译普通词硬保留成 `conditions endpoint`、`auto-configuration 类`、`annotation 注解` 这类混排。
- 单个分块遇到 `fetch failed`、连接重置或 DNS/超时类瞬时网络错误时，先按同一分块重试，避免整页从头失败。
- 分块输出按原顺序拼接为完整页面。

## 断点续跑

- 如果目标文件已存在，默认跳过。
- 使用 `--force` 才覆盖重翻。
- 可以使用 `--paths=路径1,路径2` 只重翻指定输出范围，路径相对于 latest 版本内容根目录（例如 `versions/4.1.0/content/boot`）的模块路径。
- 每次请求的 token 用量写入本地 usage 日志。
- usage 日志可以提交，因为不包含 API key。

## 命令

```bash
npm run translate:all
```

## 验收

全量翻译完成后：

```bash
npm test
npm run validate
npm run audit:completeness
npm run build
```

构建允许记录 Java API 和 Kotlin API 外部参考链接相关的日志，但命令退出码必须为 0。

Antora 原始输出包含版本前缀，例如 `build/site/boot/4.1.0/maven-plugin/index.html`。
构建后需要额外生成无版本前缀兼容入口，满足当前验收脚本和部署入口要求。

构建产物不得出现原始 `include-code::`、`Unresolved include directive` 或未渲染示例代码。`开发你的第一个 GraalVM 原生应用` 页面中 `示例应用` 小节必须渲染官方 Java 示例代码块。

构建产物和版本内容源不得出现“当前中文站暂未纳入完整生成内容”“该片段由官方构建流程生成”“该表格片段由官方构建流程生成”或“该请求或响应示例由官方构建流程生成”等占位文本。

必须生成以下兼容入口：

- `build/site/maven-plugin/index.html`
- `build/site/gradle-plugin/index.html`
- `build/site/api/rest/actuator/index.html`
