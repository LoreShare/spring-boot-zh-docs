## 已知限制

- 当前站点不包含官方构建时生成的 Javadoc 和 Kotlin API 页面。
- Java API、Kotlin API、Maven Plugin API 和 Gradle Plugin API 保持为官方外部英文链接。
- 官方构建流程生成的配置属性表、插件目标表、Actuator REST API 请求/响应片段和少量 example 片段以中文占位或本地示例补齐。
- `npm run audit:completeness` 当前仍会输出警告级别提示，主要用于后续人工排查 anchor 和低置信英文残留；警告不会阻塞构建。
- AI 翻译仍需要人工校对。
