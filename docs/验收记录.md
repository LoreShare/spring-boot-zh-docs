## 验收命令

```bash
npm test
npm run validate
npm run build
```

## 已知限制

- 这是 MVP，不是全站翻译。
- 未翻译模块的 xref 会在 Antora 构建时记录为错误日志。
- `reference`、`how-to`、`api`、`appendix` 等模块需要后续分批翻译。
- AI 翻译仍需要人工校对。

## 本地预览

```bash

```
