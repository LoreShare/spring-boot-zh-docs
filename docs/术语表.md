# 翻译术语表

## 不翻译术语

以下术语在中文文档中保持英文：

- Spring
- Spring Boot
- bean
- starter
- Actuator
- auto-configuration
- classpath
- JAR
- WAR
- annotation
- profile
- endpoint
- native image
- GraalVM
- AOT
- Buildpack
- Maven
- Gradle
- Kotlin
- Java

## 必须保留的技术文本

- AsciiDoc anchors，例如 `[[getting-started]]`。
- AsciiDoc attributes，例如 `{spring-boot-version}`。
- xref 和 link 目标，例如 `xref:installing.adoc[]`。
- include 指令。
- 代码块和命令行示例。
- inline code。
- Java 类名、包名、方法名、注解名。
- 配置键、属性名、环境变量名。
- 文件名、目录名、URL。

## 中文风格

- 普通说明翻译为自然、准确的技术中文。
- 保持技术文档语气，不使用营销式表达。
- 遇到英文术语第一次出现时，可以在中文解释后保留英文。
- 不擅自增删事实，不补充上游没有的信息。
