= 测试

Spring Boot 提供了许多实用工具和 annotation，以帮助您测试应用程序。

测试支持由两个通用模块提供——`spring-boot-test` 包含核心内容，`spring-boot-test-autoconfigure` 支持测试中的 auto-configuration——以及几个专注于特定功能的 `-test` 模块，这些模块为特定功能提供测试支持。

大多数开发者使用 `spring-boot-starter-test` starter，它同时导入了通用 Spring Boot 测试模块以及 JUnit Jupiter、AssertJ、Hamcrest 和许多其他有用的库，以及适用于其特定应用程序的专注 `-test` 模块。

[TIP]
====
如果您有使用 JUnit 4 的测试，可以使用 JUnit 6 的 vintage 引擎来运行它们。
要使用 vintage 引擎，请添加对 `junit-vintage-engine` 的依赖，如下例所示：

[source,xml]
----
<dependency>
	<groupId>org.junit.vintage</groupId>
	<artifactId>junit-vintage-engine</artifactId>
	<scope>test</scope>
	<exclusions>
		<exclusion>
			<groupId>org.hamcrest</groupId>
			<artifactId>hamcrest-core</artifactId>
		</exclusion>
	</exclusions>
</dependency>
----
====

`hamcrest-core` 被排除，转而使用属于 `spring-boot-starter-test` 的 `org.hamcrest:hamcrest`。
