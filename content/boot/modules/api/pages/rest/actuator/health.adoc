== 检索嵌套组件的健康状况

如果某个特定组件包含其他嵌套组件（如上例中的 `broker` 指示器），则可以通过向 `/actuator/health/\{component}/\{subcomponent}` 发送 `GET` 请求来检索此类嵌套组件的健康状况，如下面的 curl 示例所示：

include::partial$rest/actuator/health/instance/curl-request.adoc[]

得到的响应类似于以下内容：

include::partial$rest/actuator/health/instance/http-response.adoc[]

应用程序健康状况的组件可以根据应用程序的健康指示器及其分组方式任意深度嵌套。
健康 endpoint 支持 URL 中任意数量的 `/\{component}` 标识符，以允许检索任意深度的组件的健康状况。
