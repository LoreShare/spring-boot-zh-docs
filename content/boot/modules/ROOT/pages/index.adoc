= Spring Boot

Spring Boot 帮助您创建独立、生产级的基于 Spring 的应用程序，这些应用程序可以直接运行。我们对 Spring 平台和第三方库持有独到的见解，以便您能以最少的麻烦快速上手。大多数 Spring Boot 应用程序需要的 Spring 配置非常少。

您可以使用 Spring Boot 创建可通过 `java -jar` 启动的 Java 应用程序，或采用更传统的 war 部署方式。

我们的主要目标是：

* 为所有 Spring 开发提供一种极其快速且广泛可用的入门体验。
* 开箱即用，但一旦需求偏离默认值，能迅速让路。
* 提供一系列大型项目通用的非功能特性（例如嵌入式服务器、安全性、指标、健康检查和外部化配置）。
* 完全没有代码生成（除非针对 native image）且不需要 XML 配置。
