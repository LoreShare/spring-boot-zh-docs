= Gradle 插件

Spring Boot Gradle 插件在 https://gradle.org[Gradle] 中提供 Spring Boot 支持。
它允许你打包可执行的 jar 或 war 归档文件、运行 Spring Boot 应用程序，并使用 `spring-boot-dependencies` 提供的依赖管理。
Spring Boot 的 Gradle 插件需要 Gradle 8.x（8.14 或更高版本）或 9.x，并且可以与 Gradle 的 {url-gradle-docs}/configuration_cache.html[配置缓存] 一起使用。

除了本用户指南外，xref:api/java/index.html[API 文档] 也可用。
