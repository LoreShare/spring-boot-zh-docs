|===
|路径|类型|描述

|`+name+`
|`+String+`
|指标名称

|`+description+`
|`+String+`
|指标描述

|`+baseUnit+`
|`+String+`
|指标的基本单位

|`+measurements+`
|`+Array+`
|指标的测量值

|`+measurements[].statistic+`
|`+String+`
|测量的统计量（`TOTAL`、`TOTAL_TIME`、`COUNT`、`MAX`、`VALUE`、`UNKNOWN`、`ACTIVE_TASKS`、`DURATION`）。

|`+measurements[].value+`
|`+Number+`
|测量值。

|`+availableTags+`
|`+Array+`
|可用于下钻的标签。

|`+availableTags[].tag+`
|`+String+`
|标签名称。

|`+availableTags[].values+`
|`+Array+`
|标签的可能取值。

|===
