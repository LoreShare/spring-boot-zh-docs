|===
|路径|类型|描述

|`+calendarInterval+`
|`+Object+`
|日历间隔触发器的具体细节。

|`+calendarInterval.interval+`
|`+Number+`
|以毫秒为单位的间隔，添加到触发时间以计算下一次触发器重复的时间。

|`+calendarInterval.timeZone+`
|`+String+`
|执行时间计算所在的时区（如果有）。

|`+calendarInterval.timesTriggered+`
|`+Number+`
|触发器已触发的次数。

|`+calendarInterval.preserveHourOfDayAcrossDaylightSavings+`
|`+Boolean+`
|是否在每天的同一时间触发触发器，无论夏令时转换如何。

|`+calendarInterval.skipDayIfHourDoesNotExist+`
|`+Boolean+`
|如果一天中的某个小时不存在，是否跳过。

|===
