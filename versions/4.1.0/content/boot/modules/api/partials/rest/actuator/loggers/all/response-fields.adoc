|===
|Path|Type|Description

|`+levels+`
|`+Array+`
|日志系统支持的级别。

|`+loggers+`
|`+Object+`
|按名称索引的日志记录器。

|`+groups+`
|`+Object+`
|按名称索引的日志记录器组。

|`+loggers.*.configuredLevel+`
|`+String+`
|日志记录器的已配置级别（如果有）。

|`+loggers.*.effectiveLevel+`
|`+String+`
|日志记录器的有效级别。

|`+groups.*.configuredLevel+`
|`+String+`
|日志记录器组的已配置级别（如果有）。

|`+groups.*.members+`
|`+Array+`
|属于此组的日志记录器。

|===
