|===
|路径|类型|描述

|`+group+`
|`+String+`
|组的名称。

|`+name+`
|`+String+`
|任务的名称。

|`+description+`
|`+String+`
|任务的描述（如果有）。

|`+className+`
|`+String+`
|任务实现类的全限定名。

|`+durable+`
|`+Boolean+`
|任务在被孤立后是否应保持存储。

|`+requestRecovery+`
|`+Boolean+`
|遇到“恢复”或“故障转移”情况时是否应重新执行任务。

|`+data.*+`
|`+String+`
|任务数据映射，以键/值对形式表示（如果有）。

|`+triggers+`
|`+Array+`
|与任务关联的触发器数组（如果有）。

|`+triggers.[].group+`
|`+String+`
|触发器组的名称。

|`+triggers.[].name+`
|`+String+`
|触发器的名称。

|`+triggers.[].previousFireTime+`
|`+String+`
|触发器上次触发的时间（如果有）。

|`+triggers.[].nextFireTime+`
|`+String+`
|触发器计划下次触发的时间（如果有）。

|`+triggers.[].priority+`
|`+Number+`
|两个触发器具有相同计划触发时间时使用的优先级。

|===
