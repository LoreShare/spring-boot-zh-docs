|===
|Path|Type|Description

|`+threads+`
|`+Array+`
|JVM 的线程。

|`+threads.[].blockedCount+`
|`+Number+`
|线程被阻塞的总次数。

|`+threads.[].blockedTime+`
|`+Number+`
|线程被阻塞所花费的时间（毫秒）。如果线程竞争监视被禁用，则为 -1。

|`+threads.[].daemon+`
|`+Boolean+`
|线程是否为守护线程。仅在 Java 9 或更高版本上可用。

|`+threads.[].inNative+`
|`+Boolean+`
|线程是否正在执行本地代码。

|`+threads.[].lockName+`
|`+String+`
|线程被阻塞的对象的描述（如果有）。

|`+threads.[].lockInfo+`
|`+Object+`
|线程正在等待被阻塞的对象。

|`+threads.[].lockInfo.className+`
|`+String+`
|锁对象的完全限定类名。

|`+threads.[].lockInfo.identityHashCode+`
|`+Number+`
|锁对象的身份哈希码。

|`+threads.[].lockedMonitors+`
|`+Array+`
|此线程锁定的监视器（如果有）。

|`+threads.[].lockedMonitors.[].className+`
|`+String+`
|锁对象的类名。

|`+threads.[].lockedMonitors.[].identityHashCode+`
|`+Number+`
|锁对象的身份哈希码。

|`+threads.[].lockedMonitors.[].lockedStackDepth+`
|`+Number+`
|监视器被锁定的堆栈深度。

|`+threads.[].lockedMonitors.[].lockedStackFrame+`
|`+Object+`
|锁定监视器的堆栈帧。

|`+threads.[].lockedSynchronizers+`
|`+Array+`
|此线程锁定的同步器。

|`+threads.[].lockedSynchronizers.[].className+`
|`+String+`
|被锁定同步器的类名。

|`+threads.[].lockedSynchronizers.[].identityHashCode+`
|`+Number+`
|被锁定同步器的身份哈希码。

|`+threads.[].lockOwnerId+`
|`+Number+`
|拥有线程被阻塞对象的线程 ID。如果线程未被阻塞，则为 `-1`。

|`+threads.[].lockOwnerName+`
|`+String+`
|拥有线程被阻塞对象的线程名称（如果有）。

|`+threads.[].priority+`
|`+Number+`
|线程的优先级。仅在 Java 9 或更高版本上可用。

|`+threads.[].stackTrace+`
|`+Array+`
|线程的堆栈跟踪。

|`+threads.[].stackTrace.[].classLoaderName+`
|`+String+`
|包含此条目标识的执行点的类的类加载器名称（如果有）。仅在 Java 9 或更高版本上可用。

|`+threads.[].stackTrace.[].className+`
|`+String+`
|包含此条目标识的执行点的类的名称。

|`+threads.[].stackTrace.[].fileName+`
|`+String+`
|包含此条目标识的执行点的源文件名（如果有）。

|`+threads.[].stackTrace.[].lineNumber+`
|`+Number+`
|此条目标识的执行点的行号。如果未知，则为负数。

|`+threads.[].stackTrace.[].methodName+`
|`+String+`
|方法的名称。

|`+threads.[].stackTrace.[].moduleName+`
|`+String+`
|包含此条目标识的执行点的模块名称（如果有）。仅在 Java 9 或更高版本上可用。

|`+threads.[].stackTrace.[].moduleVersion+`
|`+String+`
|包含此条目标识的执行点的模块版本（如果有）。仅在 Java 9 或更高版本上可用。

|`+threads.[].stackTrace.[].nativeMethod+`
|`+Boolean+`
|执行点是否为本地方法。

|`+threads.[].suspended+`
|`+Boolean+`
|线程是否被挂起。

|`+threads.[].threadId+`
|`+Number+`
|线程的 ID。

|`+threads.[].threadName+`
|`+String+`
|线程的名称。

|`+threads.[].threadState+`
|`+String+`
|线程的状态（`NEW`、`RUNNABLE`、`BLOCKED`、`WAITING`、`TIMED_WAITING`、`TERMINATED`）。

|`+threads.[].waitedCount+`
|`+Number+`
|线程等待通知的总次数。

|`+threads.[].waitedTime+`
|`+Number+`
|线程等待所花费的时间（毫秒）。如果线程竞争监视被禁用，则为 -1。

|===
