[[metrics]]
= metrics

`metrics` 端点提供对应用程序指标的访问，用于诊断应用程序已记录的指标。
此端点不应在生产环境中被“抓取”或用作指标后端。
其目的是显示当前注册的指标，以便用户查看可用的指标、它们的当前值，以及触发某些操作是否会导致某些值发生变化。
如果您想通过应用程序收集的指标来诊断应用程序，应使用 xref:reference:actuator/metrics.adoc[外部指标后端]。
在这种情况下，`metrics` 端点仍然可能有用。
