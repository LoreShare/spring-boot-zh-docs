[[quartz.trigger.common-response-structure]]
=== 通用响应结构

响应具有通用结构和一个特定于触发器类型的附加对象。支持五种类型：

* `cron` 用于 `CronTrigger`
* `simple` 用于 `SimpleTrigger`
* `dailyTimeInterval` 用于 `DailyTimeIntervalTrigger`
* `calendarInterval` 用于 `CalendarIntervalTrigger`
* `custom` 用于任何其他触发器实现
