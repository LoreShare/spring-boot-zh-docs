[[sbom.retrieving-single-sbom]]
== 检索单个 SBOM

要检索可用的 SBOM，请向 `/actuator/sbom/\{id}` 发送 `GET` 请求，如下面的 curl 示例所示：

include::partial$rest/actuator/sbom/id/curl-request.adoc[]

前面的示例检索名为 application 的 SBOM。
得到的响应取决于 SBOM 的格式。
此示例使用 CycloneDX 格式。

[source,http,options="nowrap"]
----
HTTP/1.1 200 OK
Content-Type: application/vnd.cyclonedx+json
Accept-Ranges: bytes
Content-Length: 160316

{
  "bomFormat" : "CycloneDX",
  "specVersion" : "1.5",
  "serialNumber" : "urn:uuid:13862013-3360-43e5-8055-3645aa43c548",
  "version" : 1,
  // ...
}
----
