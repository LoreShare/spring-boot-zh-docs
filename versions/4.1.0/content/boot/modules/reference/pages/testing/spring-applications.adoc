[[testing.spring-applications]]
= 测试 Spring 应用

依赖注入的一大优势是它能让你的代码更容易进行单元测试。
你可以使用 `new` 操作符实例化对象，甚至无需涉及 Spring。
你也可以使用 _mock 对象_ 来代替真实的依赖。

通常，你需要超越单元测试，开始进行集成测试（使用 Spring javadoc:org.springframework.context.ApplicationContext[]）。
能够在不部署应用程序或连接其他基础设施的情况下执行集成测试是非常有用的。

Spring Framework 包含一个专门的测试模块用于此类集成测试。
你可以直接声明对 `org.springframework:spring-test` 的依赖，或者使用 `spring-boot-starter-test` starter 来传递性地引入它。

如果你之前没有使用过 `spring-test` 模块，你应该先阅读 Spring Framework 参考文档中的link:{url-spring-framework-docs}/testing.html[相关章节]。
