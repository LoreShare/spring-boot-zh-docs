[[publishing-your-application.distribution]]
== 使用 Application 插件分发

当应用 {url-gradle-docs-application-plugin}[`application` 插件]时，会创建一个名为 `boot` 的分发。
该分发包含由 `bootJar` 或 `bootWar` 任务生成的归档文件，以及用于在类 Unix 平台和 Windows 上启动它的脚本。
Zip 和 tar 分发可分别通过 `bootDistZip` 和 `bootDistTar` 任务构建。
要使用 `application` 插件，必须将其 `mainClassName` 属性配置为应用程序主类的名称。
