= process-aot

在应用程序上调用 AOT 引擎。

== 必需参数

[cols="3,2,3"]
|===
| 名称 | 类型 | 默认值

| xref:#aot.process-aot-goal.parameter-details.classes-directory[classesDirectory]
| `File`
| `${project.build.outputDirectory}`

| xref:#aot.process-aot-goal.parameter-details.generated-classes[generatedClasses]
| `File`
| `${project.build.directory}/spring-aot/main/classes`

| xref:#aot.process-aot-goal.parameter-details.generated-resources[generatedResources]
| `File`
| `${project.build.directory}/spring-aot/main/resources`

| xref:#aot.process-aot-goal.parameter-details.generated-sources[generatedSources]
| `File`
| `${project.build.directory}/spring-aot/main/sources`

|===

== 参数详情

=== `arguments`
在 AOT 处理中应考虑的应用程序参数。

[cols="10h,90"]
|===

| 名称
| `arguments`

| 类型
| `java.lang.String[]`

| 默认值
|

| 用户属性
|

| 起始版本
|

|===

=== `classesDirectory`
包含应打包到归档中的类和资源文件的目录。

[cols="10h,90"]
|===

| 名称
| `classesDirectory`

| 类型
| `java.io.File`

| 默认值
| `${project.build.outputDirectory}`

| 用户属性
|

| 起始版本
|

|===

=== `compilerArguments`
应提供给 AOT 编译过程的参数。在命令行中，请确保用引号包裹多个值。

[cols="10h,90"]
|===

| 名称
| `compilerArguments`

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性
| ``spring-boot.aot.compilerArguments``

| 起始版本
|

|===

=== `excludeGroupIds`
要排除的 groupId 名称的逗号分隔列表（精确匹配）。

[cols="10h,90"]
|===

| 名称
| `excludeGroupIds`

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性
| ``spring-boot.excludeGroupIds``

| 起始版本
| `1.1.0`

|===

=== `excludes`
要排除的工件定义集合。`Exclude` 元素定义了必需的 `groupId` 和 `artifactId` 组件以及可选的 `classifier` 组件。当配置为属性时，值应为逗号分隔，组件之间用冒号分隔：`groupId:artifactId,groupId:artifactId:classifier`

[cols="10h,90"]
|===

| 名称
| `excludes`

| 类型
| `java.util.List`

| 默认值
|

| 用户属性
| ``spring-boot.excludes``

| 起始版本
| `1.1.0`

|===

=== `generatedClasses`
包含生成的类的目录。

[cols="10h,90"]
|===

| 名称
| `generatedClasses`

| 类型
| `java.io.File`

| 默认值
| `${project.build.directory}/spring-aot/main/classes`

| 用户属性
|

| 起始版本
|

|===

=== `generatedResources`
包含生成的资源的目录。

[cols="10h,90"]
|===

| 名称
| `generatedResources`

| 类型
| `java.io.File`

| 默认值
| `${project.build.directory}/spring-aot/main/resources`

| 用户属性
|

| 起始版本
|

|===

=== `generatedSources`
包含生成的源代码的目录。

[cols="10h,90"]
|===

| 名称
| `generatedSources`

| 类型
| `java.io.File`

| 默认值
| `${project.build.directory}/spring-aot/main/sources`

| 用户属性
|

| 起始版本
|

|===

=== `includes`
要包含的工件定义集合。`Include` 元素定义了必需的 `groupId` 和 `artifactId` 组件以及可选的 `classifier` 组件。当配置为属性时，值应为逗号分隔，组件之间用冒号分隔：`groupId:artifactId,groupId:artifactId:classifier`

[cols="10h,90"]
|===

| 名称
| `includes`

| 类型
| `java.util.List`

| 默认值
|

| 用户属性
| ``spring-boot.includes``

| 起始版本
| `1.2.0`

|===

=== `jvmArguments`
应与 AOT 过程关联的 JVM 参数。在命令行中，请确保用引号包裹多个值。

[cols="10h,90"]
|===

| 名称
| `jvmArguments`

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性
| ``spring-boot.aot.jvmArguments``

| 起始版本
|

|===

=== `mainClass`
用作 AOT 过程源的主类的名称。如果未指定，将使用找到的第一个包含 'main' 方法的已编译类。

[cols="10h,90"]
|===

| 名称
| `mainClass`

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性
| ``spring-boot.aot.main-class``

| 起始版本
|

|===

=== `profiles`
在 AOT 处理中应考虑的 Spring profiles。

[cols="10h,90"]
|===

| 名称
| `profiles`

| 类型
| `java.lang.String[]`

| 默认值
|

| 用户属性
|

| 起始版本
|

|===

=== `skip`
跳过执行。

[cols="10h,90"]
|===

| 名称
| `skip`

| 类型
| `boolean`

| 默认值
| `false`

| 用户属性
| ``spring-boot.aot.skip``

| 起始版本
|

|===

=== `systemPropertyVariables`
传递给 AOT 过程的 JVM 系统属性列表。

[cols="10h,90"]
|===

| 名称
| `systemPropertyVariables`

| 类型
| `java.util.Map`

| 默认值
|

| 用户属性
|

| 起始版本
|

|===
