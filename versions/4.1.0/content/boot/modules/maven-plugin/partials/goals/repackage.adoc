[[packaging.repackage-goal]]
= `spring-boot:repackage`

`org.springframework.boot:spring-boot-maven-plugin:4.1.0`

重新打包现有的 JAR 和 WAR 归档文件，使其可以通过命令行使用 `java -jar` 执行。使用 `layout=NONE` 也可以仅用于打包带有嵌套依赖的 JAR（没有主类，因此不可执行）。

[[packaging.repackage-goal.parameter-details]]
== 参数详情

[[packaging.repackage-goal.parameter-details.attach]]
=== `attach`
将重新打包的归档文件附加到本地 Maven 仓库中安装，或部署到远程仓库。如果未配置 classifier，它将替换普通的 jar。如果已配置 `classifier`，使得普通 jar 和重新打包的 jar 不同，则它将与普通 jar 一起附加。当该属性设置为 `false` 时，重新打包的归档文件将不会被安装或部署。

[cols="10h,90"]
|===

| 名称
| `attach`

| 类型
| `boolean`

| 默认值
| `true`

| 用户属性
|

| 起始版本
| `1.4.0`

|===


[[packaging.repackage-goal.parameter-details.classifier]]
=== `classifier`
添加到重新打包归档文件的 classifier。如果未指定，主构件将被重新打包的归档文件替换。如果指定了，classifier 还将用于确定要重新打包的源归档文件：如果已存在具有该 classifier 的构件，则将其作为源并替换。如果不存在这样的构件，则使用主构件作为源，并将重新打包的归档文件作为补充构件附加到该 classifier 下。附加构件允许将其与原始构件一起部署，更多详情请参见 https://maven.apache.org/plugins/maven-deploy-plugin/examples/deploying-with-classifiers.html[Maven 文档]。

[cols="10h,90"]
|===

| 名称
| `classifier`

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性
|

| 起始版本
| `1.0.0`

|===
