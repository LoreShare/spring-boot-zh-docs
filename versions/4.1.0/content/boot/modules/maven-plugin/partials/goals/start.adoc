[[integration-tests.start-goal]]
= `spring-boot:start`

`org.springframework.boot:spring-boot-maven-plugin:4.1.0`

启动一个 Spring 应用程序。与 `run` 目标不同，此目标不会阻塞，并允许其他目标对应用程序进行操作。此目标通常用于集成测试场景，即在测试套件之前启动应用程序，并在测试套件之后停止。

[[integration-tests.start-goal.parameter-details.add-resources]]
=== `addResources`
将 Maven 资源直接添加到 classpath，这允许资源的实时就地编辑。重复的资源会从 `target/classes` 中移除，以防止在调用 `ClassLoader.getResources()` 时出现两次。请考虑将 `spring-boot-devtools` 添加到您的项目中，因为它提供了此功能以及更多功能。

[cols="10h,90"]
|===

| 名称
| `addResources`

| 类型
| `boolean`

| 默认值
| `false`

| 用户属性
| ``spring-boot.run.addResources``

| 起始版本
| `1.0.0`

|===
