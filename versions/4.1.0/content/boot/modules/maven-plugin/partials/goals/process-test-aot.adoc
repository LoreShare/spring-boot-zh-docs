== 参数详情

=== `classesDirectory`
包含用于运行测试的类和资源文件的目录。

[cols="10h,90"]
|===

| 名称
| `classesDirectory`

| 类型
| `java.io.File`

| 默认值
| `${project.build.outputDirectory}`

| 用户属性
|

| 起始版本
|

|===

=== `compilerArguments`
应提供给 AOT 编译进程的参数。在命令行中，请确保用引号包裹多个值。

[cols="10h,90"]
|===

| 名称
| `compilerArguments`

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性
| ``spring-boot.aot.compilerArguments``

| 起始版本
|

|===

=== `excludeGroupIds`
要排除的 groupId 名称的逗号分隔列表（精确匹配）。

[cols="10h,90"]
|===

| 名称
| `excludeGroupIds`

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性
| ``spring-boot.excludeGroupIds``

| 起始版本
| `1.1.0`

|===

=== `excludes`
要排除的构件定义集合。`Exclude` 元素定义了强制性的 `groupId` 和 `artifactId` 组件以及可选的 `classifier` 组件。当配置为属性时，值应为逗号分隔，组件之间用冒号分隔：`groupId:artifactId,groupId:artifactId:classifier`

[cols="10h,90"]
|===

| 名称
| `excludes`

| 类型
| `java.util.List`

| 默认值
|

| 用户属性
| ``spring-boot.excludes``

| 起始版本
| `1.1.0`

|===

=== `generatedClasses`
包含生成的测试类的目录。

[cols="10h,90"]
|===

| 名称
| `generatedClasses`

| 类型
| `java.io.File`

| 默认值
| `${project.build.directory}/spring-aot/main/classes`

| 用户属性
|

| 起始版本
|

|===

|

| 起始版本
|

|===

[cols="10h,90"]
|===

| 名称
| `generatedTestClasses`

| 类型
| `java.io.File`

| 默认值
| `${project.build.directory}/spring-aot/test/classes`

| 用户属性
|

| 起始版本

=== `includes`
要包含的构件定义集合。`Include` 元素定义了强制性的 `groupId` 和 `artifactId` 组件以及可选的 `classifier` 组件。当配置为属性时，值应为逗号分隔，组件之间用冒号分隔：`groupId:artifactId,groupId:artifactId:classifier`

[cols="10h,90"]
|===

| 名称
| `includes`

| 类型
| `java.util.List`

| 默认值
|

| 用户属性
| ``spring-boot.includes``

| 起始版本
| `1.2.0`

|===

=== `jvmArguments`
应与 AOT 进程关联的 JVM 参数。在命令行中，请确保用引号包裹多个值。

[cols="10h,90"]
|===

| 名称

| 类型
| `java.lang.String`

| 默认值
|

| 用户属性

| 起始版本
